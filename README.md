# wheelSpin

A simple React app for spinning a weighted "spin the wheel" - each slice has a
configurable weight, so probabilities don't need to be evenly split (or even
sum to 100). Built with Vite + React + TypeScript, deployed to GitHub Pages
via GitHub Actions on every push to `main`.

Live site: https://justwes2.github.io/wheelSpin/

See `docs/project-plan.md` for the original requirements, and `docs/status.md`
for implementation progress and decisions.
